=====================================================================
  HANDTRACK FOR WINDOWS — STEP BY STEP
=====================================================================

HandTrack recognises hand gestures, can hide your face, lets you draw
in the air and shows all of it in your calls through its own virtual
camera "HandTrack Camera" (Discord, Telegram, Zoom, Google Meet, Teams,
Skype, OBS).

You need: Windows 10 or 11 (64-bit), a webcam, internet during setup.


---------------------------------------------------------------------
STEP 1. DOWNLOAD
---------------------------------------------------------------------

  Option A (simpler and faster):
    1. Open this repository's Releases page (on the right on GitHub).
    2. Download  HandTrack-windows.zip

  Option B (if Releases is empty):
    1. On the repository's main page click the green "Code" button
       -> "Download ZIP".
    The installer then downloads what it needs (~400 MB, 2-5 minutes).


---------------------------------------------------------------------
STEP 2. UNZIP
---------------------------------------------------------------------

  1. Right-click the downloaded ZIP -> "Extract All..." -> "Extract".
  2. Open the new folder. It contains:
       Install HandTrack.bat     <- the installer
       Uninstall HandTrack.bat   <- the uninstaller
       Update HandTrack.bat      <- installs a newer version
       HOW-TO-INSTALL.txt        <- this guide


---------------------------------------------------------------------
STEP 3. RUN THE INSTALLER
---------------------------------------------------------------------

  1. Double-click  Install HandTrack.bat

  2. If a blue "Windows protected your PC" window appears,
     click "More info", then "Run anyway".
     (The app is free and not signed with a paid certificate, so
     Windows does not know it yet. That is normal.)

  3. A black window shows each installation step. When it asks
     "Desktop shortcut?", press Enter (= yes).

  4. Windows asks "Do you want to allow this app to make changes?" —
     click "Yes". This installs the "HandTrack Camera" virtual camera.
     The app never asks for these rights again.

  5. When the window says DONE, HandTrack starts by itself.
     Later, open it from the Start menu: HandTrack.


---------------------------------------------------------------------
STEP 4. USE IT
---------------------------------------------------------------------

  1. Press "Start": the camera picture appears.
  2. Switch on "Stream to virtual camera".
  3. In Discord / Telegram / Zoom open the video settings and choose
     the camera  "HandTrack Camera".
     Not in the list? Quit that app completely (also from the tray
     next to the clock) and open it again.

  Good to know:
    * "Hide face" puts a black mask over your face and shows a
      COVERING badge.
    * Drawing: pinch your thumb and index finger together and move
      your hand. Change the colour, thickness and how long lines stay
      on the "Effects" tab.
    * "My gestures": map a finger combination to keys, media,
      volume or launching a program.
    * Ctrl + Alt + H switches "Hide face" on and off from any program,
      also while HandTrack is in the tray. Change it in Settings.
    * Closing the window keeps HandTrack running in the tray (next to
      the clock); quit it from the tray icon's menu.


---------------------------------------------------------------------
UNINSTALL
---------------------------------------------------------------------

  Any of these:
    * double-click  Uninstall HandTrack.bat;
    * Start -> "Uninstall HandTrack";
    * Settings -> Apps -> HandTrack -> Uninstall.
  The uninstaller asks whether to delete your settings and removes the
  camera driver (Windows asks for permission once more — click "Yes").


---------------------------------------------------------------------
IF SOMETHING GOES WRONG
---------------------------------------------------------------------

  * "Could not open webcam" — another call or program is using the
    camera. Close it, or pick "Camera 2" in HandTrack.
  * A black picture saying HANDTRACK in your call — "Start" is not
    pressed in HandTrack, or streaming is switched off.
  * Reinstalling and uninstalling work even while Discord, Telegram,
    Zoom or a browser are open: a camera driver file they hold is set
    aside and removed later (at the next install or the next Windows
    sign-in).
  * Something broke or went missing — just run the installer again.
    It checks what is missing and installs only that, without
    downloading or overwriting anything else.
  * Install log: %TEMP%\handtrack-install.log
    App log:     %APPDATA%\HandTrack\logs\handtrack.log

---------------------------------------------------------------------
UPDATING
---------------------------------------------------------------------

  Start menu -> "Update HandTrack" (the installer puts it there).
  It checks GitHub for a newer version, backs up your settings,
  calibration and gestures, installs the new version (files the new
  version no longer needs are deleted) and starts HandTrack again.
  Everything you set up is kept. If it says "up to date", there is
  nothing to do. (Installed with an older version that has no such entry?
  Double-click "Update HandTrack.bat" in the unzipped folder once.)
  The backups are in %LOCALAPPDATA%\HandTrack-updater\backups.
