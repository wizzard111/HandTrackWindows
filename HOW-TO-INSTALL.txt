=====================================================================
  HANDTRACK ДЛЯ WINDOWS — ПОШАГОВАЯ УСТАНОВКА
  (English version below)
=====================================================================

HandTrack распознаёт жесты рук, может скрыть ваше лицо, рисовать в воздухе
и показывает всё это в звонках через виртуальную камеру «HandTrack Camera»
(Discord, Telegram, Zoom, Google Meet, Teams, Skype, OBS).

Нужно: Windows 10 или 11 (64-бит), веб-камера, интернет на время установки.


---------------------------------------------------------------------
ШАГ 1. СКАЧАЙТЕ
---------------------------------------------------------------------

  Вариант А (проще и быстрее):
    1. Откройте страницу Releases этого репозитория (справа на GitHub).
    2. Скачайте файл  HandTrack-windows.zip

  Вариант Б (если Releases пустые):
    1. На главной странице репозитория нажмите зелёную кнопку «Code»
       -> «Download ZIP».
    Установщик сам скачает всё нужное (~400 МБ, 2-5 минут).


---------------------------------------------------------------------
ШАГ 2. РАСПАКУЙТЕ
---------------------------------------------------------------------

  1. Нажмите на скачанный ZIP правой кнопкой -> «Извлечь всё...» -> «Извлечь».
  2. Откройте появившуюся папку. В ней:
       Install HandTrack.bat     <- установщик
       Uninstall HandTrack.bat   <- удаление
       HOW-TO-INSTALL.txt        <- эта инструкция


---------------------------------------------------------------------
ШАГ 3. ЗАПУСТИТЕ УСТАНОВЩИК
---------------------------------------------------------------------

  1. Дважды щёлкните  Install HandTrack.bat

  2. Если появится синее окно «Windows защитила ваш компьютер» —
     нажмите «Подробнее», затем «Выполнить в любом случае».
     (Программа бесплатная и не подписана платным сертификатом,
     поэтому Windows её не знает. Это нормально.)

  3. Откроется чёрное окно с шагами установки. На вопрос
     «Ярлык на рабочем столе?» нажмите Enter (= да).

  4. Windows спросит «Разрешить этому приложению вносить изменения?» —
     нажмите «Да». Это устанавливает виртуальную камеру
     «HandTrack Camera». Больше прав программа не попросит.

  5. Когда появится «ГОТОВО», HandTrack запустится сам.
     Дальше открывайте его из меню «Пуск»: HandTrack.


---------------------------------------------------------------------
ШАГ 4. ПОЛЬЗУЙТЕСЬ
---------------------------------------------------------------------

  1. Нажмите «СТАРТ» — появится изображение с камеры.
  2. Включите «Транслировать в виртуальную камеру».
  3. В Discord / Telegram / Zoom откройте настройки видео и выберите
     камеру  «HandTrack Camera».
     Если её нет в списке — полностью закройте это приложение
     (и в трее у часов) и откройте снова.

  Полезное:
    * «Скрыть лицо» — чёрная маска на лице и значок COVERING.
    * Рисование: соедините большой и указательный пальцы и ведите рукой.
      Цвет, толщину и время жизни линий меняйте во вкладке «Эффекты».
    * «Мои жесты» — назначьте комбинацию пальцев на клавиши, музыку,
      громкость или запуск программ.


---------------------------------------------------------------------
УДАЛЕНИЕ
---------------------------------------------------------------------

  Любой способ:
    * дважды щёлкните  Uninstall HandTrack.bat;
    * Пуск -> «Uninstall HandTrack»;
    * Параметры -> Приложения -> HandTrack -> Удалить.
  Деинсталлятор спросит, удалять ли настройки, и уберёт драйвер камеры
  (Windows ещё раз спросит разрешение — нажмите «Да»).


---------------------------------------------------------------------
ЕСЛИ ЧТО-ТО НЕ ТАК
---------------------------------------------------------------------

  * «Не удалось открыть веб-камеру» — камеру занял другой звонок или
    программа. Закройте её или выберите в HandTrack «Камера 2».
  * В звонке чёрный экран с надписью HANDTRACK — в HandTrack не нажат
    «Старт» или выключена трансляция.
  * Переустановка и удаление работают даже при открытых Discord, Telegram,
    Zoom и браузере: занятый файл драйвера откладывается и удаляется
    позже (при следующей установке или при следующем входе в Windows).
  * Журнал установки: %TEMP%\handtrack-install.log
    Журнал программы: %APPDATA%\HandTrack\logs\handtrack.log


=====================================================================
  HANDTRACK FOR WINDOWS — STEP BY STEP
=====================================================================

You need Windows 10 or 11 (64-bit), a webcam, and internet during setup.

STEP 1. DOWNLOAD
  Releases page -> HandTrack-windows.zip
  (or the green "Code" button -> "Download ZIP"; the installer then
  downloads what it needs, ~400 MB, 2-5 minutes).

STEP 2. UNZIP
  Right-click the ZIP -> "Extract All..." -> "Extract", open the folder.

STEP 3. INSTALL
  1. Double-click "Install HandTrack.bat".
  2. Blue "Windows protected your PC" window: "More info" -> "Run anyway"
     (the free app is not signed with a paid certificate).
  3. A black window shows each step. Press Enter for a desktop shortcut.
  4. "Do you want to allow this app to make changes?" -> "Yes".
     This installs the "HandTrack Camera" virtual camera.
  5. When it says DONE, HandTrack starts. Later: Start menu -> HandTrack.

STEP 4. USE
  Press START, switch on "Stream to virtual camera", and pick
  "HandTrack Camera" in the video settings of Discord / Telegram / Zoom.
  Not listed? Quit that app completely (also from the tray) and reopen it.

UNINSTALL
  "Uninstall HandTrack.bat", or Start -> "Uninstall HandTrack", or
  Settings -> Apps -> HandTrack -> Uninstall.
